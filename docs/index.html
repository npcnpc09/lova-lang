Programs

LOVA is built for an AI to write, check, run, repair and leave evidence in, with no person reading. Every program is a typed integer sequence. The text is a projection; the number is the program.

One function, five forms

The same pad, all the way down.

Stage-1 text is what a person or a current model writes. It expands to the core, prints as a one-byte-per-character surface, encodes to bytes, and is one integer. Every form is lossless; every tool works on the integer.

Sixty-four operators, one byte each

Eight families of eight, and the types follow position.

An operator's arguments are typed by their slot, so for any partial program the set of well-typed next tokens is computable. A generated program cannot be ill-formed. Two families were added past the core when a measured number asked for them: text and lists.

0x00–0x3F the core · 0x40–0x4F text · 0x50–0x57 lists · 88 tokens in all · lova_valid_next answers which may come next

What an unsupervised AI actually does

Six operations. Every primitive serves one.

Nothing enters the language because another language has it. A feature earns its byte with an experiment showing an AI needs it for one of these.

01

Write

Emit tokens under the type constraint. valid_next at every position; scope kept; unbound names unrepresentable.

02

Check

A program carries its own (example …) forms. lova check runs them as contracts, with a lint pass.

03

Run

Under a step and depth budget, inside a declared boundary. A host needs a function call, not a sandbox.

04

Observe

No stack traces. A deviation is a structured anomaly with kind, operator, position path and source span.

05

Repair

Patch by span. A failed example locates its fault: every single-node edit is tried, scored against the rest.

06

Evidence

Programs are values with lineage: hash, uid, why, ancestor-of. The integer is the identity.

Measured, not promised

A native VM, step for step with the reference.

The Python interpreter defines the semantics. A Rust bytecode VM reproduces it on a golden set, exact step counts included, and is the default runtime. The same runtime loads into Godot 4 as an extension class.
